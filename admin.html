🏥 University OSCE Instructor Console

นี่คือหน้าจอแผงควบคุมหลักสำหรับคณาจารย์และผู้ประเมินผล (Embeddable Admin Panel) โดยถูกจำกัดขอบเขตการดีไซน์และ CSS ให้อยู่ภายใต้ Shadow DOM อย่างสมบูรณ์ หมดกังวลเรื่องการปนเปื้อนของธีมจากหน้าเว็บสถาบันดั้งเดิม
🛠️ กล่องจำลองระบบโฮสต์อาจารย์ (Instructor Identity Simulator)
สำหรับผู้ประเมินหรืออาจารย์ ระบบต้องการสิทธิ์ `instructor-id` หรือบทบาท `role: admin` ผ่านเว็บโฮสต์เพื่อปลดล็อคการเข้าถึง จัดการเคส และดูสถิติการสอบ:
